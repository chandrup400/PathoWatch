🚀 Deploy in 5 Minutes (Free)
Step 1 — Generate VAPID Keys
In terminal: npm install web-push && node -e "const wp=require('web-push');console.log(JSON.stringify(wp.generateVAPIDKeys()))"
Copy the public and private keys into server.js
Step 2 — Deploy to Render.com (Free)
1. Create account at render.com
2. New → Web Service → Upload server.js + package.json
3. Set environment variables: VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VAPID_EMAIL
4. Click Deploy — get your URL in 2 min
Step 3 — Paste URL Above
Copy your Render URL (e.g. https://pathowatch.onrender.com) into the Server URL field above. PathoWatch will auto-save subscriptions and fire push to all devices on disease detection.
⚡ Demo Mode (No Server)
